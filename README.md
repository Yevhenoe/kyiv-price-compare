# Де дешевше — сравнение цен в Киеве

Живой поиск товара одновременно в онлайн-магазинах **Сильпо, АТБ и VARUS** с ценой за кг/л. Показываются все найденные товары, по умолчанию — от самого дешёвого за кг/л; если тот же товар есть в нескольких сетях, цены стоят рядом.

## Меню под бюджет (вкладка «Меню»)

Указываете, сколько вас, калории на человека, срок (1 день / 3 дня / неделя) и бюджет: «Дешево», «Нормально», «Розкішно», диапазон суммы или своё число. Сайт подбирает самое вкусное и разнообразное меню из ~60 рецептов, которое укладывается в бюджет, и считает, где продукты выйдут дешевле: в одном магазине или каждый продукт там, где дешевле.

- Фильтры: вегетарианское / пескетарианское, без лактозы, глютена, яиц, орехов, свинины; больше белка, меньше углеводов, быстро (до 30 мин); «не ем» отдельные продукты.
- У каждого блюда — фото (Wikimedia Commons), рецепт по шагам, КБЖУ и стоимость. Список покупок можно добавить в корзину или скопировать.
- Цены ~56 базовых продуктов собираются при запуске сервера и обновляются каждые 3 часа. Код: `src/menu-data.js` — продукты и рецепты, `src/menu.js` — сбор цен, `public/menu.js` — подбор меню.

## Как это работает

Сравниваются **только одинаковые товары**: та же марка, тот же продукт, та же фасовка.

| Магазин | Откуда цены | Как сопоставляем |
|---|---|---|
| Сильпо | API `sf-ecom-api.silpo.ua` (+ карточка товара для штрихкодов) | по штрихкоду (EAN) |
| VARUS | поиск `api.multisearch.io` + каталог `varus.ua/api/catalog` (цены магазина в Киеве) | по штрихкоду (EAN) |
| АТБ | сайт закрыт Cloudflare → headless Chromium (Playwright) | АТБ не публикует штрихкоды → по бренду, фасовке, % жирности, типу товара и всем уточнениям из названия; на сайте помечено «≈» |

Поиск идёт в два этапа (ответ потоком NDJSON):
1. **~1–2 с** — результаты поиска по всем 3 магазинам, сгруппированные по штрихкоду.
2. **~3–6 с** — для найденных товаров дозапрашиваем VARUS по штрихкодам (одним запросом), а для товаров АТБ ищем тот же бренд в остальных сетях. Страница обновляется сама.

Код: `src/match.js` — сопоставление, `src/text.js` — нормализация названий/брендов (кириллица ↔ латиница).

**Корзина** хранится в браузере (localStorage). Она считает сумму в каждом магазине и «оптимальный» вариант (каждый товар там, где он дешевле). Заказ — по ссылкам на товары в магазинах.

## Запуск локально

```bash
npm install      # заодно скачает Chromium для АТБ
npm run dev      # http://localhost:3000
```

## Деплой на VPS (Ubuntu)

```bash
# 1. Node.js 22 и pm2
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs nginx
sudo npm i -g pm2

# 2. Код (git clone или загрузить папку через scp/rsync, без node_modules)
cd /var/www/prices
npm install --omit=dev
sudo npx playwright install-deps chromium   # системные библиотеки для Chromium

# 3. Запуск с автоперезапуском
pm2 start ecosystem.config.cjs
pm2 save && pm2 startup

# 4. nginx + HTTPS
sudo cp deploy/nginx.conf /etc/nginx/sites-available/prices   # поменять домен внутри
sudo ln -s /etc/nginx/sites-available/prices /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo apt install -y certbot python3-certbot-nginx && sudo certbot --nginx -d example.com
```

Минимум для VPS: 1 vCPU, **1–2 ГБ RAM** (Chromium для АТБ потребляет ~200–400 МБ).

## Настройки (переменные окружения, см. `src/config.js`)

| Переменная | По умолчанию | Что это |
|---|---|---|
| `PORT` | 3000 | порт сервера |
| `VARUS_SHOP` | 98 (Демиевская, 27) | магазин VARUS, чьи цены показываем: 67 Волынская, 139260 Малышко, 139261 Вышгородская, 130700 Героев полка «Азов» |
| `SILPO_BRANCH` | онлайн-магазин | id филиала Сильпо |
| `ATB_ENABLED` | 1 | `0` — отключить АТБ (если Cloudflare блокирует IP сервера) |
| `CACHE_TTL` | 600 | кэш в секундах |

## Возможные проблемы

- **АТБ «временно недоступен»** — Cloudflare может блокировать IP некоторых дата-центров. Попробуйте другой VPS-провайдер (лучше украинский) или поставьте `ATB_ENABLED=0`.
- Магазины могут поменять API/вёрстку — тогда правится только соответствующий файл в `src/stores/`.
